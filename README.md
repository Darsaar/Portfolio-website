# Sarthak Patidar · Portfolio

Personal portfolio site: a single static page (`index.html`) with no build step.

- **Case studies:** Blinkit (supply analytics), Google Photos (AI discovery engine and Memory Match MVP), Ola Saathi (0→1 strategy). Each one has an interactive console and a full case-study pop-up.
- **Assets:** `resume.pdf`, plus the case-study decks in `decks/`.

## Run locally

```
python3 -m http.server
```

Then open http://localhost:8000.

## Deploy

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
